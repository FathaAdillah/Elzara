# Register Verifikasi Threat Model — Elzara

Tanggal: 2026-11-22 · Status: **inventaris bukti, bukan kelulusan seluruh kontrol**.

## 1. Dasar dan batas klaim

Sumber: [threat model](threat-model.md) §1–§7, Task 19 pada `.codex/plans/2026-11-17-sprint-0-fondasi.md`, Doc 03 0.13/1.10 dan ADR-007 D-6a. Task 19 Step 1 menentukan format `id T-n | kontrol | berkas test | perintah | hasil | status`; Step 2 melarang menaikkan kontrol tanpa bukti.

Inspeksi awal kode dan **badan tes** pada basis PR #39 `6fff64c` tidak menjalankan suite aplikasi/checker endpoint. **Pembaruan hardening 2026-11-22:** cabang turunan PR #42 menambahkan pagar Host/Origin, CORS per surface, cookie host-only dan SSR Host eksplisit sesuai ADR-007 D-6a. Run lokal `php artisan test --testsuite=Feature,Contract`: **236 passed, 27 skipped (3409 assertions)**; Unit: **19 passed (229 assertions)**. Chromium mandiri dua host: **1 passed**. Lint/PHPStan/Deptrac B1–B6/B2 lulus. Hanya baris yang menyebut run hardening di bawah mendapat bukti run baru; kontrol lain tetap hasil inspeksi awal. Skip media/search bukan lulus integrasi live. Bukan bukti deployment, edge/TLS produksi, cutover cookie lama atau re-approval pemilik.

Sufiks T-n.a/b memecah penegak berbeda pada ancaman yang sama; seluruh T-01…T-42 tercakup. Satu baris menyatukan kontrol yang berbagi penegak/cakupan bukti; gap/tindakan yang belum terbukti ditulis eksplisit. S-1…S-8 menambahkan cakupan §/batas yang melampaui satu ancaman, termasuk cookie/CSRF/2FA/guard separation.

- **teruji**: ada asersi langsung untuk lingkup yang disebut; bukan klaim run baru atau seluruh ancaman selesai.
- **sebagian**: ada sebagian bukti, tetapi lingkup lebih luas belum terbukti atau checker belum menjadi gate runtime CI.
- **tanpa tes**: ⚑ belum ditemukan pembuktian; tidak otomatis berarti kode tidak ada.
- **belum diimplementasi**: fitur/penegak bisnis masih desain. Fixture fondasi tidak disamakan dengan produksi.
- Label `[desain]` threat model adalah baseline resep; status granular terkini ada di register ini. Tidak menaikkan seluruh T-n ke `[terpasang]` jika masih memiliki gap.

## 4. Ringkasan dan gap

**Sign-off diperbarui 2026-11-22:** pemilik menyetujui ulang threat model subdomain admin terpisah dengan persetujuan klien, disampaikan Product Engineer. Cakupan: cookie sesi dan CSRF admin host-only, pemeriksaan origin admin tepat, CORS per host dan tes isolasi storefront/admin; 2FA serta guard terpisah tidak berubah. Persetujuan bukan bukti rollout: kontrol kini diimplementasi dan diuji lokal di PR #45; P0.10 ditutup atas keputusan lead 2026-11-22; verifikasi edge/TLS, keselarasan env nyata dan cutover cookie domain induk lama diteruskan ke P0.19/M4, bukan klaim deployment produksi.

Hasil hitung baris §3: **98 kontrol/paket** — **25 teruji**, **36 sebagian**, **20 tanpa tes**, **17 belum diimplementasi**. Bukan jumlah ancaman tertutup; satu T-n memiliki status campuran. Delapan baris S mengulang lingkup §, bukan delapan fitur baru.

1. Orders/Payments/webhook/refund/ledger, PoBatch/enrollment, UGC, quotation, claim/proof marketplace, GRN dan WA belum dibuktikan end-to-end. Fixture runner/inbox/kuota tidak menggantikan implementasi. Gate 1.000 checkout/500 enrollment dan race expiry/payment belum tersedia.
2. Matriks CSRF route×guard×origin, SSR tamu, larangan token/secret bundle, semua aksi berisiko menghasilkan audit, append-only DB/arsip dan role DB terpisah belum terbukti menyeluruh.
3. Subdomain admin produksi dipilih pemilik 2026-11-22; ADR-007 D-6a/TB-3 diperbarui, re-approval tercatat 2026-11-22; implementasi tersedia di cabang PR #45; rollout edge/TLS belum diverifikasi. Pagar route/bootstrap Host, origin admin dan CORS per surface kini diuji API/Chromium lokal (T-02.e/T-03.e–g); edge/TLS produksi dan cutover cookie induk lama belum diverifikasi.
4. WAF/Waiting Room/bypass, cache poisoning antar pelanggan, kapasitas/isolasi/TLS staging, k6/Playwright dan checker header runtime belum memiliki artefak run pada register ini.
5. PII scrub log bukan pembuktian Sentry/provider/query presigned. Secret scanning/rotasi/expiry, retensi, SBOM/provenance/runtime hardening, approval template WA serta review KI/observasi tetap gap.
6. Reader/relink backup bukan restore offsite PostgreSQL+object/PITR terintegrasi sebelum launch. Skrip drill bukan hasil RPO/RTO staging.
7. Sign-off Fatharoni 2026-11-22 dan penerimaan retroaktif urutan Task 19 (disampaikan Product Engineer tanggal sama) hanya bentuk satu host. Ia tetap bukti historis, bukan bukti teknis atau persetujuan amandemen subdomain; re-approval pemilik dengan persetujuan klien tercatat 2026-11-22; implementasi tersedia di cabang PR #45; rollout edge/TLS belum diverifikasi.

**Verdict P0.10: ditutup atas keputusan lead 2026-11-22; hold dicabut.** Sign-off ulang pemilik untuk subdomain admin terpisah sudah tercatat pada base. Binding Host/origin, Origin admin tepat, CORS per host dan cookie host-only diimplementasi dengan bukti API + Chromium dua host di PR #45; lead juga mengonfirmasi run aplikasi nyata Nuxt admin + storefront Next hasil build (localhost vs admin.localhost) lulus 2026-11-22. Register dan interim ADR-008 tersedia; gateway/kurir/WA/brand/PO cukup dilacak. Rollout edge/TLS, keselarasan env nyata dan cutover/pembersihan cookie domain induk lama menjadi verifikasi rilis P0.19/M4; belum ada deployment produksi. Matriks penuh bisnis route×guard T-03.c tetap DoD Sprint 1+. Penutupan Task 19 bukan klaim seluruh kontrol threat model teruji, deployment atau penutupan Phase 0.

Pemilik tindak lanjut: pemilik modul untuk tes fitur, penanggung jawab rilis untuk gate/artefak lingkungan, pemilik proyek/klien untuk keputusan eksternal dan topologi. Tambahkan tanggal/perintah/artefak run nyata saat tersedia.
